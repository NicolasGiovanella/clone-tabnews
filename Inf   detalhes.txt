********* NVM *********
NVM - NVM é a sigla para Node Version Manager, uma ferramenta de linha de comando que permite gerenciar e instalar diferentes versões do Node.js.

criar arquivo .nvmrc(o RC é uma convecção criada que significa run commands), ele possuem instruções de inicialização, nesse caso para o NVM

nvm install - vai executar diretamente oque já tem no .nvmrc
